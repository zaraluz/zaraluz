### 👋 Hi, I'm Zara Louise!

I'm an **Analytics Engineer** with a background in **Business Administration** and 3+ years of hands-on experience in **Data Analytics, Analytics Engineering, and Data Warehousing**.

I specialize in transforming raw operational data into structured, scalable analytics environments — from **dbt models** to **Power BI** dashboards that other teams actually use to make decisions.

In my current role as a **Data Analyst at a Brazilian retail supermarket chain**, I built the company's data function from scratch: a dimensional **Data Warehouse (Star Schema) on AWS** (S3, Glue, Athena) and a **dbt pipeline** (staging → intermediate → marts) with automated tests and generated documentation.

Previously, I worked as a **Data Analyst at SeguroBet** (fintech), integrating systems via REST API and building 15+ **Power BI dashboards** across large-scale datasets (~50M rows). Earlier, during an international, 100% English-speaking project in **Germany**, I worked as a Data Analyst building data models, dashboards, and information flows for a logistics company.

Today, I combine:
- 📊 Business vision
- 🧠 Analytical thinking
- ☁️ Cloud & Data Architecture
- 🧱 Analytics Engineering (dbt, ETL/ELT)
- 🤖 Machine Learning foundations

I'm currently deepening my expertise through an **MBA in Data Science & Analytics** at USP, building scalable BI environments that go beyond dashboards — focusing on data quality, governance, and long-term data strategy.

I love transforming complexity into clarity — whether through a well-designed data model, an automated pipeline, or a strategic dashboard.

Outside of work, I enjoy learning new technologies, exploring datasets, and creating handmade projects — because building things from scratch is something I truly value.

📊 *Turning data into structure. Structure into insight. Insight into impact.*
